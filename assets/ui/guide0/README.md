# GUIDE-0 초상화 넣는 곳

여기에 파일을 넣기만 하면 임시 `GUIDE-0 PORTRAIT` 박스가 자동으로 최종 도트 얼굴로 바뀐다.
**코드도, 데이터 파일도 고칠 필요 없다.**

## 파일 목록

### 얼굴 (표정마다 한 장)

| 파일명 | 언제 쓰이나 |
|---|---|
| `guide0_normal_base.png` | 기본 표정 (대부분의 대사) |
| `guide0_smile_base.png`  | 웃는 표정 ("걱정하지 마십시오. 제가 도와드리겠습니다." / 칭찬할 때) |
| `guide0_sneer_base.png`  | 비웃는 표정 (신원 불일치를 말할 때 등) |

`_base` 는 **입이 없는 얼굴**이라는 뜻이다. 입은 아래의 Overlay 로 따로 얹힌다.

> 입까지 그려진 옛 그림(`guide0_normal.png` 처럼 `_base` 가 없는 이름)도 계속 쓸 수 있다.
> 같은 표정에 두 파일이 다 있으면 **`_base` 쪽이 이긴다.** `_base` 가 없는 표정은
> 입 Overlay 없이 그림 그대로만 그린다(입이 움직이지 않는다).

### 입 (얼굴 위에 겹쳐 그린다)

| 파일명 | 모양 |
|---|---|
| `guide0_MouthClosed.png` | 다문 입 |
| `guide0_MouthSmall.png`  | 작게 열린 입 |
| `guide0_MouthOpen.png`   | 크게 열린 입 |

**입 그림은 얼굴과 캔버스 크기가 같아야 한다.** (지금은 1000 x 1000)
게임이 좌표를 계산하지 않고 얼굴을 맞춘 사각형에 그대로 겹쳐 그리기 때문에,
캔버스만 같으면 입 위치가 어긋날 일이 없다. 잘라내거나 옮기지 말 것.

### 글리치용

| 파일명 | 언제 쓰이나 |
|---|---|
| `guide0_horrorface.png` | 대사를 다 읽고도 한참 넘기지 않으면 **아주 잠깐(0.09초)** 스치는 얼굴 |

이 그림만은 홀로그램 색으로 물들이지 않고 원본 색 그대로 그린다 —
빨간 눈이 하늘색에 묻히지 않게 하기 위함이다.

## 규격

- 권장: **정사각형** (예: 512 x 512 또는 1000 x 1000). 비율을 유지한 채 칸에 맞춰 들어간다.
  - 프롤로그의 왼쪽 CRT 얼굴 화면 : 328 x 328 칸
  - 그 외(오른쪽 CRT 작은 초상) : 164 x 164 칸
- **색은 흰색(또는 밝은 회색)으로 그리면 된다.** 게임이 홀로그램 하늘색으로 물들여 그린다.
  (`guide0_horrorface.png` 만 예외 — 위 참고)
- **배경은 투명(알파 0)으로 둘 것.** 흰 배경째로 넣으면 네모 전체가 하늘색으로 칠해진다.
- 형식: `.png` 우선. `.webp` / `.jpg` 도 자동으로 찾는다(`.jpg` 는 투명을 못 담으니 비권장).
- 도트 그림이면 임포트 설정에서 **Filter 를 끄는 것**을 권장한다
  (Godot: 파일 선택 → 임포트 탭 → Detect 3D 해제 / Filter 해제 → 다시 임포트).

## 표정을 더 늘리고 싶다면

1. `guide0_<새표정키>_base.png` 를 이 폴더에 넣는다(입 없는 얼굴).
2. `docs/NSP_PROLOGUE_RUNTIME.md` 의 해당 `@guide` 블록에서 `portrait: <새표정키>` 로 적는다.

입 Overlay 는 표정과 무관하게 공용이므로 따로 만들 필요가 없다.
표정은 대사 중간에도 바꿀 수 있다 — 블록 안에서 `portrait:` 줄을 만나는 순간 교체된다.

```
@guide g_day0_open
portrait: normal
line: 관리자 업무는 이번이 처음이시군요.
portrait: smile
line: 걱정하지 마십시오. 제가 도와드리겠습니다.
```

## 입 움직임을 조정하려면

`scripts/prologue/GuideMouthAnimator.cs` 위쪽 상수만 고치면 된다.

| 상수 | 뜻 |
|---|---|
| `FrameSeconds` | 입 모양이 바뀌는 간격(기본 0.075초) |
| `PunctuationHold` | `,` `?` `!` `.` 에서 잠깐 다무는 시간 |
| `EllipsisHold` | `...` 처럼 점이 이어질 때 더 길게 쉬는 시간 |
| `Pattern` | 말할 때 도는 입 모양 순서 |
| `IdleBeforeGlitch` / `GlitchGapMin~Max` / `GlitchDuration` | 호러 얼굴이 스치는 타이밍 |
