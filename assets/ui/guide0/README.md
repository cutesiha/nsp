# GUIDE-0 초상화 넣는 곳

여기에 파일을 넣기만 하면 임시 `GUIDE-0 PORTRAIT` 박스가 자동으로 최종 도트 얼굴로 바뀐다.
**코드도, 데이터 파일도 고칠 필요 없다.**

| 파일명 | 언제 쓰이나 |
|---|---|
| `guide0_normal.png` | 기본 표정 (대부분의 대사) |
| `guide0_smile.png`  | 웃는 표정 ("걱정하지 마십시오. 제가 도와드리겠습니다." / 칭찬할 때) |

- 권장 규격: **정사각형** (예: 256 x 256 또는 512 x 512). 화면에서 176 x 176 창에 비율 유지로 들어간다.
- 형식: `.png` 우선. `.webp` / `.jpg` 도 자동으로 찾는다.
- 도트 그림이면 임포트 설정에서 **Filter 를 끄는 것**을 권장한다
  (Godot: 파일 선택 → 임포트 탭 → Detect 3D 해제 / Filter 해제 → 다시 임포트).

## 표정을 더 늘리고 싶다면

1. `guide0_<새표정키>.png` 를 이 폴더에 넣는다.
2. `docs/NSP_PROLOGUE_RUNTIME.md` 의 해당 `@guide` 블록에서 `portrait: <새표정키>` 로 적는다.

표정은 대사 중간에도 바꿀 수 있다 — 블록 안에서 `portrait:` 줄을 만나는 순간 교체된다.

```
@guide g_day0_open
portrait: normal
line: 관리자 업무는 이번이 처음이시군요.
portrait: smile
line: 걱정하지 마십시오. 제가 도와드리겠습니다.
```
