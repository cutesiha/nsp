# 토끼 (rabbit) — 활발 / 긍정 / 밝음 / 낙천 / 즉흥 / 솔직 / 기분파
# 말투 기준(작성자 지정):
#   어디 있었냐 → "정비실에 있었어요! 거기서 열심히 일했어요! 칭찬해 주세요."
#   누구랑 있었냐 → "늑대 씨요! 솔직히 포스가 있으셔서 좀 무서웠는데, 별 일 없었어요."
#   느낌표가 많고, 생각나는 대로 솔직하게 말한다. 칭찬받고 싶어 하고, 자기 기분이 말에 그대로 묻어난다.
#   무서운 일에도 금방 호기심이 이긴다("근데 좀 궁금하긴 했어요!"). 해요체, 격식은 거의 없다.
# 이 파일에 없는 슬롯은 common.txt 의 공통 문장을 쓴다.

@char rabbit
