# 양 (sheep) — 소심 / 자신감 없음 / 항상 말을 더듬음 / 늘 자기가 뭘 잘못했나 걱정
# 말투 기준(작성자 지정):
#   어디 있었냐 → "저, 저는 저장고에 있었어요... 혹시 제, 제가 뭘 잘못했나요...?"
#   누구랑 있었냐 → "그, 그때는 토끼 씨랑 있었어요... 왜 물어보시는 거예요...?"
#   거의 모든 문장에 더듬기("저, 저는", "그, 그때", "제, 제가")가 있고 말끝이 흐려진다("...", "...?").
#   질문을 받으면 먼저 자기가 혼나는 건 아닌지 걱정한다. 본 것과 추측은 조심스럽게 나눈다.
# 주의: 더듬기는 '아, 어, 음, 네' 로 시작하지 않는다(자연스러움 필터가 반복 반응어로 오인해 지운다).
# 이 파일에 없는 슬롯은 common.txt 의 공통 문장을 쓴다.
