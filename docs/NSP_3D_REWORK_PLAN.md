# NSP 3D 전면 개편 방향

## 0. 개편 목표

기존 NSP는 각 기능이 `시작 → 근무 배치 → 메인 근무 → 근무 정산 → 휴게시간 → 다음 날`처럼 각각 독립된 2D 씬으로 분리되어 있어, 기능은 이어지지만 플레이 경험은 화면을 넘겨가며 진행하는 TRPG/관리 UI처럼 느껴졌다.

이번 3D 개편의 목표는 **중앙제어실을 게임 전체의 공간적 중심으로 만들고, 대부분의 기능이 이 한 공간 안에서 자연스럽게 이어지는 것처럼 느껴지게 하는 것**이다.

실제 코드상 Scene이 여러 개로 나뉘어 있어도 상관없다. 중요한 것은 플레이어가 체감할 때:

> “다른 메뉴로 넘어갔다”가 아니라  
> “같은 중앙제어실에서 다음 업무를 시작했다”

고 느끼는 것이다.

### 핵심 방향

- 중앙제어실 = 게임 전체의 허브이자 기준 공간
- 화면 전환보다 **카메라 이동 / 조명 변화 / 모니터 화면 변화 / 실제 책상 오브젝트 상호작용**으로 단계 전환
- 기존 2D 기능 UI를 그대로 3D 화면에 붙이는 방식은 지양
- 텍스트 설명을 줄이고, 가능한 정보는 공간·소리·오브젝트·짧은 UI로 전달
- 기존 게임 로직과 시뮬레이션은 최대한 유지
- 프롤로그는 이번 개편 범위에서 잠시 제외

---

# 1. 전체 플레이 흐름

```text
[시작 화면]
3D 중앙제어실 배경
        ↓
[근무 배치]
책상 위 배치표
        ↓
[메인 근무]
왼쪽 시설 모니터 + 오른쪽 CCTV + 전화
        ↓
[근무 종료 / 정산]
같은 제어실에서 결과 확인
        ↓
[휴게시간 / 인터뷰]
같은 제어실에서 CCTV + 전화로 직원과 대화
        ↓
[다음 날]
책상 위 새 배치표 / 금기 확인
        ↓
[메인 근무]
...
        ↓
[최종 결과]
```

각 단계는 가능하면 **같은 중앙제어실을 공유한다.**

# 2. 공통 공간 — 중앙제어실

현재 이미 구현되어 있는 3D 중앙제어실을 게임 전체의 기준으로 사용한다.

필수 오브젝트:

- 플레이어 좌석 / 고정 1인칭 카메라
- 책상
- 왼쪽 CRT 모니터
- 오른쪽 CRT 모니터
- 전화기
- 키보드
- 근무 서류 / 배치표를 놓을 공간
- 경고등 또는 작은 상태등
- 환풍구
- 형광등
- 배관 / 케이블 / 산업시설 소품

중앙제어실 자체는 매 단계마다 새로 디자인하지 않는다.

대신 단계에 따라 다음 요소만 변한다.

- 카메라 위치 / 시선
- 책상 위 오브젝트
- CRT 화면
- 조명 상태
- 환경음
- 전화 사용 여부
- 표시되는 최소 HUD

---

# 3. 시작 화면

## 목표

기존의 별도 2D TitleScene 느낌을 없애고, 게임을 켠 순간부터 중앙제어실에 들어와 있는 느낌을 준다.

## 연출

3D 중앙제어실을 그대로 배경으로 사용한다.

처음에는:

- 화면에 약한 Blur 또는 Depth of Field
- 중앙제어실은 어둡게
- CRT는 꺼져 있거나 약하게 노이즈만 출력
- 환풍구 / 형광등 / 기계음은 작게 들림

그 위에 최소 UI만 표시한다.

```text
야간근무지침
NIGHT SHIFT PROTOCOL

[근무 시작]
[이어하기]
[설정]
[종료]
```

## 시작 버튼

`근무 시작` 선택 시 별도의 화면으로 즉시 Cut하지 않는다.

권장:

1. 제목 UI Fade Out
2. Blur 제거
3. 중앙제어실 환경음 선명해짐
4. 책상 쪽으로 카메라가 자연스럽게 이동
5. 근무 배치 단계 시작

즉 Title → Schedule이 메뉴 전환이 아니라 **같은 장소가 활성화되는 느낌**이어야 한다.

# 4. 근무 배치

## 기존 문제

기존 2D에서는 별도 배치 Scene으로 이동하여 직원들을 UI 슬롯에 넣는 기능이었다.

3D에서는 이 기능을 **책상 위 실제 관리자 업무**로 바꾼다.

## 기본 연출

카메라가 책상 위를 내려다본다.

책상 위:

- 오늘의 근무 배치표
- 직원 카드 또는 직원 코드네임 목록
- 오늘의 금기 / 지침 종이
- 펜 또는 간단한 사무용품

예시:

```text
DAY 2 근무 배치표

발전실    [          ]
환기실    [          ]
정비실    [          ]
의무실    [          ]
경비실    [          ]
코어실    [          ]
저장고    [          ]
```

## 직원 배치 표현

구현 난도에 따라 둘 중 하나를 선택한다.

### A. 직원 카드 배치

직원 카드 6개를 책상에 두고,
카드를 드래그하여 배치표의 작업실 칸에 놓는다.

### B. 직접 기록하는 느낌

직원 선택 → 작업실 선택 시
해당 코드네임이 종이에 적히는 애니메이션/효과를 준다.

완전한 필기 시뮬레이션까지 만들 필요는 없다.

## 근무 확정

근무 배치 완료:

1. `근무 시작` 확인
2. 손이 배치표를 한쪽으로 밀거나 종이를 정리
3. 카메라가 책상에서 다시 정면으로 올라옴
4. 두 CRT가 켜짐
5. 짧은 부팅음
6. `NIGHT SHIFT START`
7. 곧바로 메인 근무 시작

Schedule → Main 사이에 검은 화면 Scene Cut을 최소화한다.

# 5. 메인 근무

현재 구현된 3D 중앙제어실 Main을 기준으로 한다.

단, 기존 2D MainScene 전체를 CRT에 집어넣는 방식은 사용하지 않는다.

## 왼쪽 CRT — 시설 관리 모니터

역할:

- 시설 미니맵
- 작업실 상태
- 직원 위치
- 발생 중인 업무
- 남은 시간
- 위험 / 금기
- 선택된 직원 또는 방 정보
- Event Log

시설은 단순한 노드/네모 연결 구조로 보여준다.

방이나 직원을 클릭하면 별도 큰 Popup을 띄우지 않고
CRT 안의 고정 Inspector 영역을 변경한다.

## 오른쪽 CRT — CCTV

역할:

- 선택한 작업실 CCTV
- 직원 현재 모습
- 사보타주 흔적
- 이상현상
- 정전 / 신호 장애
- 방별 Blender 렌더 배경

왼쪽에서 작업실 선택
→ 오른쪽 CCTV가 해당 방으로 변경.

## 전화

전화는 UI 버튼이 아니라 책상 위 실제 3D 오브젝트.

전화 수신:

- 실제 벨소리
- 전화기 또는 표시등 반응
- 클릭 시 수화기 들기
- 카메라가 전화 쪽으로 약간 이동
- 통화 중 대화 텍스트는 읽기 쉬운 2D HUD 사용 가능

## 사고 / 공포

기존의 큰 중앙 Popup에 의존하지 않는다.

사고가 발생하면:

- 왼쪽 모니터 노드 점멸
- 경고음
- 오른쪽 CCTV 이상
- 실제 중앙제어실 조명 Flicker
- 경고등
- 필요하면 카메라 미세 흔들림

정보 전달은 확실하게 하되,
“텍스트 박스를 읽는 게임”이 되지 않도록 한다.

---

# 6. 근무 종료 / 근무 정산

## 목표

기존 SettlementScene처럼 갑자기 별도 결과 UI로 넘어가는 느낌을 줄인다.

근무 시간이 끝나면 중앙제어실 안에서 근무가 종료된다.

## 종료 연출

예:

1. 시계가 종료 시간에 도달
2. 시설 경고음/업무 알림이 멈춤
3. `SHIFT COMPLETE`
4. 환풍기와 기계 소리가 조금 잦아듦
5. 조명이 조금 안정됨
6. 왼쪽 또는 오른쪽 CRT가 `SHIFT REPORT` 화면으로 전환

## 정산 화면

긴 문장 대신 숫자와 핵심 결과 위주.

```text
DAY 2 — SHIFT REPORT

CORE       +12%
MATERIAL   +7

사고        2
금기 위반   1
격리        0
생존        6 / 6
```

필요하면 중요한 사건 2~3개만 표시.

```text
02:13 발전실 과열
03:02 CCTV 신호 손실
03:18 정비실 설비 파손
```

기존처럼 텍스트가 한 페이지 가득 나오지 않게 한다.

## 선택적 연출

나중에 여유가 있으면:

- 작은 프린터에서 근무 보고서가 출력됨
- 플레이어가 종이를 집어서 확인

등으로 발전 가능.

필수는 아니다.

---

# 7. 휴게시간 / 직원 인터뷰

## 목표

기존 별도 VN/대화 Scene을 없애고,
관리자가 계속 중앙제어실에 앉아 직원들을 확인하고 인터뷰하는 느낌으로 변경한다.

## 기본 구조

근무 종료 후:

- 제어실 조명이 조금 어두워짐
- 시설 전체 분위기가 조용해짐
- 왼쪽 모니터는 근무 기록 / 직원 목록
- 오른쪽 모니터는 휴게실 또는 직원 인터뷰 CCTV

플레이어가 직원 한 명을 선택한다.

직원 선택:

1. 오른쪽 CCTV 화면이 해당 직원으로 전환
2. 2D 일러스트의 얼굴/상반신을 CCTV 화면에 사용
3. 전화 또는 인터컴을 통해 대화
4. 대화 텍스트는 짧고 읽기 쉽게 표시

예:

```text
● REC
BREAK ROOM

[FOX 일러스트]

FOX:
“관리자님, 무슨 일이십니까?”
```

## 캐릭터 일러스트 활용

현재 제작 중인 직원 일러스트는 여기에서 적극 사용한다.

3D 캐릭터 모델 6명을 새로 제작할 필요는 없다.

- 3D 중앙제어실
- CCTV 배경
- 2D 직원 일러스트

를 조합한 하이브리드 방식으로 구성한다.

## 대화

휴게시간이 이 게임에서 텍스트가 가장 많이 나오는 구간이 될 수 있으므로,
다른 단계보다 오히려 이곳에 대화를 집중시킨다.

그 대신:

- 한 번에 긴 문단 금지
- 한 대사 1~2문장 중심
- 질문 선택지는 짧게
- 반복 정보 최소화

향후 Claude API 대화 시스템이 들어가더라도
이 화면 구조 안에서 작동하도록 한다.

---

# 8. 다음 날 전환

휴게시간 종료 후 별도의 새로운 메뉴 화면으로 이동하지 않는다.

권장 연출:

1. 통화 종료
2. CCTV OFF 또는 화면 전환
3. 잠깐 Fade
4. 시간 / DAY 표시 변경
5. 책상 위에 새 배치표와 오늘의 지침이 놓임
6. 카메라가 다시 책상을 내려다봄

그리고 다시 **근무 배치 → 메인 근무** 루프로 연결된다.

즉 플레이어 체감상:

```text
밤 근무
→ 정산
→ 인터뷰
→ 다음 날 서류
→ 다음 근무
```

가 모두 같은 자리에서 계속 이어진다.

---

# 9. 최종 결과

Day 5 종료 후에도 처음에는 중앙제어실에서 결과를 보여준다.

예:

코어 100% 달성:

- 코어 상태 정상화
- CRT의 경고 표시가 사라짐
- 시설 전체 전력이 안정
- 조명이 정상으로 돌아옴
- 중앙제어실 소리가 평온해짐

또는 실패:

- 경고등
- CRT 오류
- 시설 Shutdown

그 후 필요하다면 별도 Ending Scene으로 넘어갈 수 있다.

최종 엔딩까지 반드시 중앙제어실 한 방에서 처리할 필요는 없다.

핵심은 **게임의 운영 루프까지는 중앙제어실을 중심으로 유지하는 것**이다.

---

# 10. 텍스트 감소 원칙

이번 3D 개편에서 중요한 목표 중 하나.

기존 게임이 텍스트 중심/TRPG처럼 느껴지는 문제를 줄인다.

## 줄일 것

- 큰 설명 Popup
- 긴 업무 설명
- 매 단계마다 등장하는 안내문
- 반복되는 시스템 설명
- 긴 정산 문장
- 모든 이벤트를 Log 문장으로만 전달하는 것

## 대신 사용할 것

- 아이콘
- 경고등
- 소리
- 게이지
- 직원 움직임
- CCTV 변화
- 방 상태 변화
- 모니터 색 변화
- 실제 전화벨
- 조명 Flicker
- 짧은 상태 텍스트

예:

기존:

> 발전실에서 문제가 발생했습니다. 발전기를 즉시 점검하지 않을 경우 전력 공급에 문제가 발생할 수 있습니다.

개편:

```text
BEEP BEEP

[발전실 노드 RED]

⚠ GENERATOR OVERHEAT
00:12
```

+ 오른쪽 CCTV에 발전실 표시.

# 11. Scene 구조 권장안

가능하다면 중앙제어실 환경 자체는 하나의 재사용 가능한 Scene으로 분리한다.

예:

```text
ControlRoomEnvironment.tscn
```

그리고 각 Phase가 이를 공유한다.

또는 더 좋은 구조라면
하나의 3D Main/Hub Scene 안에서 Phase만 변경해도 된다.

예:

```text
ControlRoomHub
│
├ Environment3D
├ PlayerSeatRig
├ Desk
├ Phone3D
├ LeftMonitor
├ RightMonitor
├ HUD
└ GamePhaseController
```

GamePhase 예:

```text
TITLE
SCHEDULE
SHIFT
SETTLEMENT
REST
RESULT
```

각 Phase에 따라:

- Camera target
- Monitor content
- Desk objects
- Interaction availability
- Lighting
- Audio
- HUD

만 변경한다.

### 중요

현재 프로젝트 구조를 확인해서
기존 Scene 구조를 완전히 갈아엎는 것보다 위험하다면
기존 Scene 분리를 유지해도 된다.

단, 모든 Scene이 동일한 중앙제어실 환경과 카메라 연출을 공유하여
플레이어에게는 하나의 공간처럼 보여야 한다.

# 12. 유지해야 할 기존 시스템

# 14. 단계별 구현 우선순위

## PHASE 1 — 전체 구조 연결

- 현재 3D 중앙제어실을 공통 기준 공간으로 정리
- 시작 화면을 중앙제어실 배경으로 변경
- 근무 배치를 책상 위 작업으로 변경
- 근무 확정 → 현재 3D Main으로 자연스럽게 연결

이 단계의 목표:

> 시작 → 배치 → 메인 근무가 하나의 공간처럼 연결되는지 확인

---

## PHASE 2 — 근무 후 루프 연결

- 메인 근무 종료 연출
- 근무 정산을 CRT Report로 변경
- 휴게시간을 CCTV + 전화 인터뷰로 변경
- 다음 날 배치로 자연스럽게 복귀

이 단계의 목표:

> 배치 → 근무 → 정산 → 휴게 → 다음 배치가 하나의 완전한 루프로 느껴질 것

---

## PHASE 3 — 몰입 / 텍스트 감소 / 폴리싱

- 불필요한 Popup 제거
- 긴 텍스트 축소
- 환경음
- 모니터 부팅/종료
- 전화벨
- 카메라 Tween
- 손/팔 연출
- 조명 변화
- 경고등
- CCTV 노이즈
- 공포 연출
- Scene 전환 Fade 최소화

# 15. 최종 체감 목표

기존 NSP:

> 배치 화면을 연다  
> → 게임 화면으로 간다  
> → 정산 화면을 연다  
> → 대화 화면으로 간다

3D 개편 NSP:

> 책상에서 근무표를 작성한다  
> → 고개를 들고 모니터로 시설을 관리한다  
> → 전화가 오면 직접 받는다  
> → 근무가 끝나면 모니터로 보고서를 확인한다  
> → CCTV를 통해 직원을 불러 인터뷰한다  
> → 다음 날 새 근무표가 책상에 놓인다

기능 자체는 비슷해도,
플레이어가 **“UI를 넘기는 사람”이 아니라 “야간 관리자” 역할을 수행하고 있다고 느끼는 것**이 이번 개편의 핵심이다.
