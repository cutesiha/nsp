# NSP — DAY 1 EVENT CONTENT (REVISED)

> DAY 1 프로토타입의 금기 이상현상, 시설 사고, 파괴공작을 현재 3D 운영 구조에 맞춰 재정의한다.
>
> 핵심 흐름: **배치 → 경고 → 재배치 → 전력/정보 선택 → 감시 공백 → 파괴공작 → 추리**

## 0. 공통 원칙

- 사건 판정은 Godot가 담당한다.
- 이유 없는 랜덤 사고 금지. 업무 방치, 금기 위반, 파괴공작, 전력 상태 등 명확한 원인에서 발생한다.
- 신규 게이지 남발 금지. 기존 스트레스/자재/코어/전력만 활용한다.
- DAY 1 활성 금기는 **1개**. DAY 1은 `TABOO-01 발전실 인원 제한` 고정.
- 금기는 작은 수치 페널티가 아니라 **크고 즉각적이며 시청각적으로 명확한 이상현상**을 일으킨다.
- 시설 사고는 반드시 **소리 + CCTV/미니맵 시각 변화 + 실제 기능 손실**을 함께 가진다.
- `업무 우선도` 시스템은 사용하지 않는다.
- `수동 구역 봉쇄`는 사용하지 않는다.
- 전력은 `LIGHTING / CCTV / SENSOR` 세 기능을 대상으로 한다.

# 1. 파괴공작

현재 구조는 대부분 유지한다.

## SAB-01 감시 사각
- 파괴공작자가 작업실에 있음.
- 해당 방 CCTV를 보고 있지 않음.
- 후보 행동: 업무 방해 / 설비 고장 / 정상 근무 위장.
- 목적: 한 방을 보면 다른 방이 사각이 되는 구조.

## SAB-02 전력 공백
- LIGHTING 또는 CCTV가 꺼져 정보가 부족한 구역.
- 후보 행동: 설비 파손 / 업무 방해 / 비밀 이동 / 조건부 살인 기회.
- 목적: 전력 배분 선택이 추리 난이도에 직접 영향을 주게 함.

## SAB-03 단독 작업
- 혼자 일정 시간 이상 + CCTV 미감시.
- 후보 행동: 업무 진행도 감소 / 설비 고장 / 자재 방해.
- DAY 1 필수 아님.

## SAB-04 혼란 악용
- 다른 방 긴급 사고/금기 이상현상 활성.
- 플레이어가 그쪽 대응 중이고 파괴공작자는 사각에 있음.
- 후보 행동: 작은 설비 방해 / 업무 방해 / 비밀 이동.
- DAY 1 필수 아님.

## SAB-05 조건부 살인
- 파괴공작자 + 일반 직원 1명만 같은 방.
- CCTV 미감시.
- LIGHTING/CCTV 상태 또는 사고 때문에 행동을 확실히 확인하기 어려움.
- 다른 직원 즉시 목격 불가.
- 하루 살인 제한 미초과.
- DAY 1 최대 1회.
- 플레이어가 잘 관리하면 살인이 발생하지 않을 수도 있어야 함.

# 2. 금기 이상현상 설계 원칙

금기는 단순히 `~하지 마시오 + 작은 수치 감소`가 아니다.

모든 금기는 다음 구조를 가진다.

1. 위반 상태 진입
2. 짧은 유예시간
3. 강한 시청각 전조
4. 큰 운영 페널티 발동
5. 일정 시간 또는 수리/재배치 후 회복

플레이어가 즉시:
> "내가 방금 금기를 어겨서 큰일이 났다."
라고 이해할 수 있어야 한다.

---

## TABOO-01 발전실 인원 제한 — DAY 1 고정

### 금기
**발전실에 동시에 두 명 이상의 직원을 머물게 하지 마십시오.**

### 위반 조건
발전실 2명 이상이 일정 유예시간 이상 함께 존재.

### 전조
- 발전실 조명이 흰색 → 붉은색.
- 발전기 소리가 낮고 불규칙하게 떨림.
- CCTV 프레임 끊김/잔상.
- SENSOR ON:
  `⚠ PROTOCOL VIOLATION — POWER ROOM`
  `00:08`

### 발동
- 강한 전기 충격음 + 금속 타격음.
- 중앙제어실 조명 순간 정전.
- Monitor 01 발전실 노드 강한 적색 점멸.
- 발전실 CCTV 일시 단절.
- **전력 용량 3 → 1 급락.**
- 일정 시간 또는 점검 완료 전까지 회복되지 않음.

### 의도
발전실 사고가 급하면 2명을 보내고 싶지만,
금기를 어기면 정보망 전체가 크게 무너진다.

---

## TABOO-02 환기실 단독 근무 제한

### 금기
**담력이 가장 낮은 직원을 환기실에 혼자 두지 마십시오.**

### 전조
- 환풍기 회전음 불규칙.
- CCTV 가장자리에 습기/검은 노이즈.
- 직원 스트레스 상승.
- SENSOR ON이면 위반 카운트다운.

### 발동
- 환풍기 갑작스러운 역회전/금속 마찰음.
- 해당 직원 업무 중단 및 이탈.
- 스트레스 크게 상승.
- **환기 기능 완전 정지.**
- 전 직원 스트레스 지속 상승.
- 다른 직원을 보내 정상화 필요.

---

## TABOO-03 세 번의 경보 후 이동 금지

### 금기
**종이 세 번 울린 뒤 30초 동안 작업실 간 이동을 금지합니다.**

### 전조
- 시설 전체에서 동일한 종소리 3회.
- SENSOR ON: `MOVEMENT PROHIBITED 00:30`
- Monitor 01 통로 붉은 표시.

### 위반 결과
- 이동 경로 조명이 연속해서 꺼짐.
- 해당 직원 아이콘 일시 소실.
- CCTV에서도 잠시 위치 확인 불가.
- 해당 직원은 잠시 이동/업무 명령 불가.

### 구현 우선도
DAY 1 이후.

---

## TABOO-04 암전 중 호출 금지

### 금기
**조명이 꺼진 작업실에 있는 직원의 코드네임을 호출하지 마십시오.**

### 전조
- 통화 연결음 뒤 비정상 잡음.
- 직원 음성 전에 짧은 다른 응답/숨소리.
- CCTV 순간 왜곡.

### 발동
- 해당 방 CCTV 강제 노이즈.
- 해당 직원 위치 아이콘 일정 시간 소실.
- 해당 직원 스트레스 크게 상승.
- 통화 채널 일정 시간 잠김.
- CCTV에 짧은 이상 실루엣 연출 가능.

### 구현 우선도
DAY 1 이후.

# 3. 시설 사고 / 고장

사고는:

`업무 방치 → SENSOR 경고 → 시청각 전조 → 실제 고장 → 기능 손실 → 재배치/수리 → 복구`

순서로 진행한다.

---

## FAIL-01 발전기 과열 — DAY 1 고정 사고

### DAY 1 구조
근무 시작 후 정해진 시점에 **발전기 점검 업무**가 반드시 발생한다.

사고 자체를 강제로 터뜨리는 것이 아니라:
`점검 업무 발생 → 방치 시 사고` 구조를 유지한다.

### SENSOR ON 경고
`⚠ GENERATOR OVERHEAT`
`FAILURE IN 00:20`

### 전조
- 거칠어지는 발전기 소리.
- 스파크.
- CCTV의 옅은 연기.
- 발전실 조명 깜빡임.
- 시간이 가까워질수록 증상 강화.

### 방치 결과
- 큰 금속 폭음/차단음.
- 발전실 연기 + 스파크.
- 중앙제어실 주 조명 OFF / 비상등 ON.
- **POWER CAPACITY = 0**
- LIGHTING OFF
- CCTV OFF
- SENSOR OFF

### 정전 중
- 일반 작업실 직원 아이콘 소실.
- 비상 조명 방인 **코어실 / 경비실**만 직원 위치 확인 가능.
- 파괴공작자가 정보 공백을 이용할 수 있음.

### 복구
확실히 위치가 보이는 직원 중 한 명을 발전실로 재배치해 수리.

복구 연출:
`POWER RESTORING...`
`LIGHTING ... ONLINE`
`SENSOR ...... ONLINE`
`CCTV ........ ONLINE`

### 사건 발견
정전 중 살인/사보타주가 있었다면 복구 후:
`⚠ LIFE SIGNAL LOST`
로 처음 발견.

---

## FAIL-02 환기 필터 막힘

### 경고
`⚠ VENTILATION PRESSURE`
`FAILURE IN 00:20`

### 전조
- 환풍기 속도 저하.
- `푸슉`, `칙칙` 압력 누출음.
- 덕트 증기/먼지.
- 중앙제어실 환풍기 환경음도 약해짐.

### 사고 결과
- 환풍기 정지.
- 큰 공기 배출음 후 비정상적인 정적.
- **전 직원 스트레스 지속 상승.**
- 수리 전까지 지속.

---

## FAIL-03 정비 설비 고장

### 경고
`⚠ MAINTENANCE MACHINE`
`FAILURE IN 00:20`

### 전조
- 금속 갈리는 소리.
- 스파크.
- 연기.

### 사고 결과
- 큰 기계 파손음.
- **자재 생산 완전 정지.**
- 기존 자재는 사용 가능.
- 자재 0이 되면 코어 수리 정지.
- 정비실 수리 완료 후 생산 재개.

### 중요
기존 `CorridorLock` 결과는 폐기한다.

---

## FAIL-04 감시 시스템 오류

### 경고
`⚠ SURVEILLANCE SYSTEM`
`FAILURE IN 00:20`

### 전조
- CCTV Static.
- 프레임 드롭.
- 잡음.
- 간헐적 Blackout.

### 사고 결과
- **CCTV 시스템 강제 OFFLINE.**
- 전력을 CCTV에 줘도 수리 전까지 사용 불가.
- Monitor 02: `SIGNAL FAILURE`
- 경비실 수리 완료 후 복구.

# 4. SENSOR / ALERT TERMINAL

책상 위 작은 `ALERT TERMINAL`이 사전 경고를 담당한다.

## SENSOR ON
표시:
- 사고 종류
- 방
- 남은 시간
- 금기 위반 카운트다운
- 코어 자재 부족

## SENSOR OFF
- 정확한 사전 경고/카운트다운 없음.
- 실제 사고 발생 순간 최소한의 `FACILITY FAILURE`만 표시.

# 5. DAY 1 고정 흐름

1. 근무 배치
   - 코어실 최소 1명 필수.
   - 금기 = TABOO-01 발전실 2인 금지.
2. 정상 근무
   - LIGHTING / CCTV / SENSOR ON.
3. 발전기 점검 업무 발생.
4. SENSOR 20초 경고.
5. 플레이어 선택
   - 적합한 직원 1명 투입
   - 늦게 대응
   - 급하다고 2명을 보내 금기 위험 감수
6. 발전 사고 또는 금기 이상현상 가능.
7. 심각한 전력 손실 / 정전.
8. 정보망 붕괴.
9. 비상 조명 방 직원으로 발전실 복구.
10. 정보 공백 동안 파괴공작 기회.
11. 전력 복구.
12. 사건이 있었다면 복구 후 발견.
13. 남은 근무.
14. 정산.
15. 직원 인터뷰/추리.

# 7. 검증 질문

1. 코어실 1명 강제가 실제 인력난을 만드는가?
2. 발전실 사고가 정보망 붕괴로 이어지는가?
3. TABOO-01 때문에 발전실 2인 투입이 실제 유혹/위험이 되는가?
4. LIGHTING / CCTV / SENSOR 중 무엇을 포기할지 고민하는가?
5. 사고가 소리/연기/스파크/모니터 변화로 체감되는가?
6. 금기 위반이 정말 무섭고 큰 선택으로 느껴지는가?
7. 정보 공백이 파괴공작 기회로 자연스럽게 연결되는가?
8. 살인/사보타주가 랜덤 억까가 아니라 내가 놓친 시간의 결과처럼 느껴지는가?
9. 한 사고 때문에 다른 방 인력을 빼야 하는 연쇄 판단이 생기는가?
10. 다시 플레이할 때 다른 선택을 해보고 싶은가?
