# 코드가 읽기 쉽게 재배열했다. 문장 자체를 수정하거나 창작하지 말 것.
#
# 미완성/보류 항목(원본 4번 "XX", 살인 목격 등)은 여기에 넣지 않는다.
#
# 파싱 규칙:
#   '#' 로 시작하는 줄, 빈 줄 = 무시
#   @event <id>        현재 이벤트 컨텍스트
#   @char  <id>        현재 캐릭터 (owl/cat/jellyfish/rabbit/crow/fox)
#   opening: <text>    (이벤트) 캐릭터가 먼저 거는 통화의 첫 대사
#   greeting: <text>   (general_call) 플레이어가 걸었을 때의 첫 인사
#   choice: <text>     (이벤트) 플레이어 선택지 — 바로 다음 reply 와 짝
#   reply: <text>      (이벤트) 위 choice 에 대한 캐릭터의 대답
#   q: <text>          (general_call) 플레이어 질문 — 바로 다음 a 와 짝
#   a: <text>          (general_call) 위 q 에 대한 캐릭터의 대답
#
# 캐릭터 id ↔ 코드네임: owl=올빼미 cat=고양이 jellyfish=해파리 rabbit=토끼 crow=까마귀 fox=여우
