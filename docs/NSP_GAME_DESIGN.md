# 야간근무지침 (가제) — GAME DESIGN

> AI 에이전트가 프로젝트의 확정 기획을 이해하기 위한 기준 문서다.  
> 이 문서에 없는 시스템·설정·콘텐츠를 임의로 추가하지 않는다. 모호한 사항은 구현 전에 사용자에게 확인한다.

## 1. 한 줄 피치

**직원 중 살인마가 숨어 있다. 서로 충돌하는 시설의 금기를 지키며 5일 안에 봉쇄 코어를 복구하라.**

## 2. 장르

- 고난도 공포 시설 경영 시뮬레이션
- 실시간 운영
- 사회적 추리
- Claude API 기반 NPC 대화

## 3. 핵심 원칙

- 스토리가 게임의 재미를 대신하지 않는다.
- 핵심 재미는 `근무 배치 → 실시간 운영 → 사고 대응 → 직원 대화/의심`에서 나와야 한다.
- 시스템을 추가해 재미를 보강하기보다, 기존 핵심 시스템끼리 상호작용하도록 만든다.
- 완성작 스코프는 **5일 / 직원 6명**을 상한으로 한다.

## 4. 세계관

### 외부
시설 밖에서는 대규모 재난이 진행 중이다.

- 재난은 시설의 금기와 직접 관련이 없다.
- 정확한 재난 종류는 후속 기획에서 결정한다.
- 외부 재난은 플레이어가 시설을 떠날 수 없는 이유와 제한된 시간의 근거다.

### 시설
재난 이전부터 존재했던 수상한 지하시설이다.

- 시설 내부에는 오래전부터 이해할 수 없는 금기와 근무 수칙이 존재했다.
- 금기는 전 세계의 법칙이 아니라 **이 시설 내부에만 한정**된다.
- 모든 직원은 동물 가면과 코드네임을 사용한다.
- 직원의 본명, 얼굴, 실제 신원을 확인하려 해서는 안 된다.
- 왜 이런 규칙이 존재하는지는 초반부터 전부 설명하지 않는다.

### 봉쇄 코어
시설 내부의 봉쇄·생명유지 계통을 총괄하는 핵심 장치다.

- 외부 재난으로 크게 손상되었다.
- 플레이어는 **DAY 5 종료 시 봉쇄 코어를 100% 상태로 유지**해야 한다.
- 수리 업무로 진행도가 상승한다.
- 파괴공작 또는 일부 대형 사고로 진행도가 감소할 수 있다.
- 100%에 일찍 도달해도 즉시 게임이 끝나지 않는다. DAY 5까지 보호해야 한다.

## 5. 하루의 게임 흐름

1. **근무 준비**
   - 오늘의 금기 2개 확인
   - 시설 상태 / 업무 목표 확인
   - 직원 능력치와 스트레스 확인
2. **근무표 작성**
   - 직원에게 담당 업무와 주 작업 구역을 배정
3. **실시간 시설 운영**
   - 직원들이 실제로 시설 내부를 이동하며 업무 수행
   - 플레이어가 사고와 수상 행동에 개입
4. **근무 정산**
   - 코어 진행도 / 자재 / 금기 위반 / 사건 로그 확인
5. **휴식 시간**
   - 직원들과 Claude 기반 대화
   - 사건에 대해 질문
   - 필요 시 직원 1명 격리
   - 본편에서는 모듈 업그레이드 가능
6. **다음 날**

## 6. 직원 시스템

### 본편 인원
- 직원 6명
- 이 중 1명은 파괴공작자 / 살인마
- 플레이어는 관리자이며 직원 수에 포함하지 않는다.

### 능력치
직원 수치 능력치는 아래 3개만 사용한다.

| 능력치 | 기능 |
|---|---|
| 기술 | 수리, 설비, 코어 복구 효율 |
| 담력 | 금기 현상, 시체, 위험 구역에서 패닉에 버티는 능력 |
| 관찰 | 수상 행동, 사고 원인, 목격 정보 포착 |

### 동적 상태
**스트레스 0~100 하나만 사용한다.**

- 스트레스가 높으면 업무 효율 저하 또는 명령 거부 가능성이 생길 수 있다.
- 별도의 피로, 호감도, 신뢰도, 정신력 게이지를 만들지 않는다.
- `alive`, `isolated` 등은 단순 구조 상태이며 별도 수치 게이지가 아니다.

### 성격
각 캐릭터는 **3문장 정도의 짧은 성격 설정**을 가진다.

예시 구조:
- 규칙을 얼마나 잘 지키는가
- 타인에게 어떻게 반응하는가
- 위험할 때 어떤 태도를 보이는가

이 성격은 Claude NPC 프롬프트의 중심 자료가 된다.

### 기억
- NPC는 자신이 직접 목격하거나 전달받은 사건만 안다.
- 모든 직원에게 전체 사건의 진실을 제공하지 않는다.
- 최근 대화 내용은 짧은 요약 형태로 유지한다.

## 7. 시설 구조

### 본편 핵심 모듈

| 모듈 | 기능 |
|---|---|
| 중앙 관리실 | 플레이어의 메인 화면 / 두 모니터 |
| 발전실 | 전력 확보 |
| 환기실 | 생존 기능 유지 |
| 정비실 | 자재 확보 및 장비 수리 |
| 의무실 | 스트레스 회복 보조 / 사고 대응 |
| 경비실 | CCTV / 봉쇄 / 감시 효율 강화 |

### 건설 방식
- ONI식 자유 타일 건설은 사용하지 않는다.
- **고정 연결 슬롯에 방 모듈을 활성화하거나 업그레이드**하는 정도로 제한한다.
- 프로토타입에서는 건설/확장을 구현하지 않는다.

## 8. 근무표

근무표는 “직원이 하루 종일 한 방에 서 있으라”는 명령이 아니다.

근무표에는 다음이 들어간다.

- 담당 업무
- 주 작업 구역
- 필요 인원
- 권장 능력치
- 업무 우선도

직원은 업무를 수행하기 위해 실제로 이동할 수 있다.

### 정상적인 이동 이유
- 부품 수령
- 보고
- 다른 직원 지원
- 치료 / 대피
- 짧은 개인 행동

### 수상한 이동
- 명령에 없는 구역 방문
- 특정 직원 추적
- CCTV 사각지대로 이동
- 금기 유도
- 설비 방해

## 9. 실시간 운영 화면

게임의 메인 근무 화면은 **중앙 관리실의 두 개 모니터**다.

### MONITOR 01 — 시설 지도
- 네모 모듈로 연결된 시설 전체 표시
- 직원의 현재 위치와 이동 표시
- 담당 업무
- 설비 고장
- 문 잠금
- 전력 상태
- 금기 위험 표시

### MONITOR 02 — CCTV
MONITOR 01에서 선택한 방의 실시간 CCTV를 표시한다.

- 직원 행동
- 직원 간 대화
- 수상 행동
- 이상현상
- 사건 현장

각 모니터는 클릭하면 화면 대부분을 차지하도록 확대할 수 있고 취소하면 두 모니터 화면으로 복귀한다.

## 10. 실시간 관리자 기능

| 기능 | 역할 |
|---|---|
| 통화 연결 | 전화로 직원과 짧은 대화(2지선다) / 물리적 이동 없음 |
| 직원 대화 | 선택 직원에게 질문하고 Claude의 응답을 말풍선으로 출력 |
| 재배치 | 근무 중 담당 업무/구역 수정 |
| 구역 봉쇄 | 사고·살인·이상현상 확산 차단 |
| 전력 배분 | CCTV, 환기, 조명 등의 전력 우선순위 변경 |
| 업무 우선도 | 동시에 여러 사고가 발생했을 때 처리 순서 결정 |

재배치에는 별도 행동 포인트를 만들지 않는다. 대신 이동 시간과 기존 작업 진행 손실이 비용이 된다.

## 11. 금기 시스템

### 기본 규칙
- 하루 활성 금기: 2개
- 본편 금기 풀: 6~8개 정도
- 금기마다 위반 조건과 결과가 정해져 있다.
- 무작위 수치 감소가 아니라 **실제 새로운 운영 문제**를 발생시킨다.
- 플레이어는 반복 플레이를 통해 금기의 위험을 학습할 수 있어야 한다.

### 결과 유형
- 직원 스트레스 상승 / 고립
- 시설 정전 / 고장
- 통로 잠금 / 업무 중단
- CCTV와 지도 정보 불일치 같은 이상현상

### 예시
- `23시 이후 발전실에 혼자 있지 말 것` → 정전 / CCTV 단절
- `종이 세 번 울린 뒤 복도를 건너지 말 것` → 해당 통로 일시 폐쇄
- `적색등 아래에서 코드네임을 부르지 말 것` → 관측 정보 이상

## 12. 파괴공작자 / 살인마

### 목적
살인마의 목적은 사람을 많이 죽이는 것이 아니다.

**DAY 5까지 봉쇄 코어 100% 달성을 저지하면서 자신의 정체를 숨기는 것**이 목표다.

### 가능한 행동
- 정상 근무
- 거짓말
- 다른 직원에게 거짓 지시
- 설비 방해
- 금기 악용
- 살인 시도
- 다른 직원에게 의심 돌리기

### 살인 규칙
- 본편 전체 성공 살인: **최소 0회 / 최대 2회**
- 하루 최대 1회
- 살인은 고정 스크립트가 아니다.
- 배치, CCTV, 다른 직원 위치, 금기, 플레이어 개입에 따라 실제 기회가 있을 때만 시도한다.
- 플레이어가 잘 관리하면 5일간 0명이 죽을 수도 있다.

### 격리
- 플레이어는 한 번에 직원 1명만 격리할 수 있다.
- 격리 직원은 근무에 참여할 수 없다.
- 일반 직원을 잘못 격리하면 인력 손실이 발생하고 진범은 계속 활동한다.
- 진범을 격리해도 게임은 끝나지 않는다.
- 진범 격리 후에는 파괴공작이 멈춰 이후 운영이 쉬워진다.
- 진범인지 여부를 즉시 “정답”으로 알려주지 않는다.

## 13. Claude API 역할

### Claude가 하는 일
- 캐릭터 성격에 맞는 자연스러운 대화 생성
- NPC가 알고 있는 사실 범위 안에서 질문에 답변
- 최근 플레이어와의 대화를 반영
- 후속 개발 단계에서 허용된 행동 후보 중 하나를 선택하는 AI 판단 보조

### Claude가 하면 안 되는 일
- 게임 상태 직접 수정
- 임의의 아이템/방/사건 생성
- 자신이 알 수 없는 게임의 전체 진실 사용
- 허용 목록에 없는 행동 실행
- 승패, 금기 판정, 살인 성공 여부 직접 결정

### 역할 분리
**Claude = 의도 / 표현**  
**Godot = 사실 / 판정 / 실행**

### NPC 프롬프트 최소 정보
- 코드네임
- 성격 3문장
- 능력치
- 현재 스트레스
- 현재 업무 / 위치
- 본인이 알고 있는 사실
- 최근 대화 요약
- 살인마인 경우에만 숨은 목적과 허용 행동

## 14. 근무 결과 / 보상

별도 점수 시스템을 만들지 않는다.

근무 결과로 다음이 남는다.

- 봉쇄 코어 진행도
- 자재
- 시설 전력 상태
- 금기 위반 기록
- 사건/출입/CCTV 로그
- 생존 직원 수
- 추리에 사용할 수 있는 목격 정보

## 15. 승패

### CLEAR
**DAY 5 종료 시 봉쇄 코어 100%**

살인마를 못 잡아도 CLEAR다.

최종 결과 보고서에만:
- `내부 파괴공작자: 격리 완료`
- 또는 `내부 파괴공작자: 미확인`

으로 표시한다.

별도의 TRUE / NORMAL / BAD 엔딩 트리를 만들지 않는다.

### FAIL
- DAY 5 종료 시 봉쇄 코어가 100% 미달
- 또는 활동 가능한 직원이 0명이라 운영 자체가 불가능

## 16. 본편 스코프 상한

| 항목 | 상한 |
|---|---|
| 일수 | 5일 |
| 직원 | 6명 |
| 능력치 | 3개 |
| 수치형 직원 상태 | 스트레스 1개 |
| 핵심 시설 모듈 | 6종 |
| 하루 활성 금기 | 2개 |
| 금기 전체 풀 | 6~8개 |
| 살인 성공 | 0~2회 |
| 엔딩 | CLEAR / FAIL |

### 만들지 않을 것
- 식량/수분/피로/호감도/신뢰도 등 추가 게이지
- 자유 타일 기반 대규모 건설
- 10명 이상의 직원
- 방대한 개인 스토리 분기
- 여러 캐릭터별 엔딩
- 매일 다른 전용 미니게임
