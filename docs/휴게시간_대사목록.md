# 야간근무지침 — DAY1 휴게시간 로컬 인터뷰 대사 데이터

> 목적: Claude API가 작동하지 않아도 매 판 랜덤으로 지정되는 방해자와 일반 직원의 휴게시간 인터뷰가 정상 작동하도록 하는 로컬 대사 기준 문서.
>
> **중요:** 방해자는 특정 캐릭터로 고정하지 않는다. 매 게임 시작 시 6명 중 1명을 랜덤 지정하고, 같은 캐릭터라도 현재 역할이 `CIVILIAN`인지 `SABOTEUR`인지에 따라 아래 대사 세트를 선택한다.

---

## 0. 공통 구현 규칙

### 역할
- `CIVILIAN`: 일반 직원. 본인이 실제로 알고 있는 정보만 말한다.
- `SABOTEUR`: 방해자. 캐릭터의 평소 성격을 유지하면서 일부 사실을 생략·왜곡·회피한다.
- 방해자는 실제 런타임 역할값으로 판정한다. 특정 캐릭터와 역할을 하드코딩하지 않는다.

### 기본 질문 5개
- `Q1_ANOMALY`: "오늘 근무 중 이상한 점은 없었습니까?"
- `Q2_WHERE`: "사고 당시 어디에 있었습니까?"
- `Q3_SUSPICIOUS`: "수상한 행동을 한 직원을 봤습니까?"
- `Q4_OPINION`: "{TARGET} 직원을 어떻게 생각합니까?"
- `Q5_ACCUSE`: "현재 당신을 의심하고 있습니다."

### 변수
- `{TIME}`: 목격/사건 시각
- `{ROOM}`: 관련 작업실
- `{SELF_ROOM}`: 본인이 실제로 있던 작업실
- `{TARGET}`: 질문 대상 직원
- `{SUSPECT}`: 수상 행동을 목격한 직원
- `{INCIDENT}`: 발생한 사고/이상현상
- `{DETAIL}`: 실제 목격 세부 정보

### 정보가 없을 때
일반 직원은 모르는 사실을 만들어내지 않는다. `Q1~Q3`에서 실제 기억이 없다면 `NO_INFO` 대사를 사용한다.

방해자는 무조건 거짓말하지 않는다. 사실 대부분을 유지하면서 자기에게 불리한 부분만 숨기는 방식을 우선한다.

# 1. 올빼미

## 기본 성격
원칙주의. 단정하고 책임감이 강하며 규칙을 중요하게 생각한다. 침착하고 배려심 있으며 보고 후 허가를 기다리는 타입.

## 말투
정중하고 차분하다. 사실과 추측을 구분하고 불필요하게 감정적이지 않다.

## 방해자일 때 거짓말 방식
사실 대부분을 말하되 자기에게 불리한 부분만 생략한다. 노골적인 거짓말보다 "그 부분까지는 확인하지 못했습니다" 식으로 정보 범위를 줄인다.

### Q1_ANOMALY
**CIVILIAN / HAVE_INFO**
> "{TIME}쯤 {ROOM}에서 {INCIDENT}와 관련된 이상 징후가 있었습니다. 제가 직접 확인한 건 {DETAIL}까지입니다."

**CIVILIAN / NO_INFO**
> "제가 직접 확인한 이상은 없었습니다. 다른 직원의 보고까지는 확인하지 못했습니다."

**SABOTEUR**
> "눈에 띄는 이상은 있었습니다만, 제가 직접 확인한 범위에서는 시설 사고로 보였습니다. 단정해서 말씀드리기는 어렵습니다."

### Q2_WHERE
**CIVILIAN**
> "사고 당시에는 {SELF_ROOM}에 있었습니다. 이동 기록을 확인하시면 같은 내용이 나올 겁니다."

**SABOTEUR**
> "당시 주 업무 구역은 {SELF_ROOM}이었습니다. 그 외의 짧은 이동까지 전부 기억하고 있지는 않습니다."

### Q3_SUSPICIOUS
**CIVILIAN / HAVE_INFO**
> "{TIME}경 {ROOM}에서 {SUSPECT}씨의 행동을 봤습니다. {DETAIL}. 다만 그것만으로 방해 행위라고 단정할 수는 없습니다."

**CIVILIAN / NO_INFO**
> "제가 직접 수상하다고 판단할 만한 행동은 보지 못했습니다."

**SABOTEUR**
> "특별히 확신할 만한 행동은 없었습니다. 섣불리 다른 직원을 의심하고 싶지는 않습니다."

### Q4_OPINION
**CIVILIAN**
> "{TARGET}씨는 맡은 일은 하는 편입니다. 다만 오늘 행동에 대해서는 제가 직접 본 부분만 판단하는 게 맞을 것 같습니다."

**SABOTEUR**
> "{TARGET}씨를 특별히 의심할 이유는 없습니다. 다만 오늘처럼 상황이 불안정할 때는 누구든 실수할 수 있다고 생각합니다."

### Q5_ACCUSE
**CIVILIAN**
> "저를 의심하시는 이유가 있다면 말씀해주십시오. 제가 확인할 수 있는 범위에서는 전부 설명드리겠습니다."

**SABOTEUR**
> "알겠습니다. 의심 자체는 관리자님의 판단이니까요. 다만 추측보다 기록과 실제 행동을 먼저 확인해주셨으면 합니다."

# 2. 고양이

## 기본 성격
독불장군. 효율을 중시하고 예민하며 깔끔하다. 신경질적이고 까칠하지만 머리가 빠르다.

## 말투
짧고 직설적이며 툭툭 쏜다. 핵심 정보는 비교적 정확하게 말한다.

## 방해자일 때 거짓말 방식
자기 행동을 합리화하고 다른 직원의 실수·비효율을 강조한다.

### Q1_ANOMALY
**CIVILIAN / HAVE_INFO**
> "{ROOM} 쪽이 이상했어요. {TIME}쯤 {DETAIL}. 그걸 설마 모르고 계셨던 건 아니죠?"

**CIVILIAN / NO_INFO**
> "제가 본 건 없어요. 이상한 게 있었으면 진작 보고했겠죠."

**SABOTEUR**
> "딱히요. 시설 자체가 엉망이라 평소랑 구분도 안 가던데요. 굳이 하나 꼽자면 다른 애들 동선이 좀이상했어요."

### Q2_WHERE
**CIVILIAN**
> "{SELF_ROOM}에 있었어요. 로그 보면 나오잖아요."

**SABOTEUR**
> "주로 {SELF_ROOM}이요. 사고 때문에 잠깐 움직인 건 있을 수 있는데, 그게 그렇게 중요한가요?"

### Q3_SUSPICIOUS
**CIVILIAN / HAVE_INFO**
> "{SUSPECT}씨를 봤어요. {TIME}쯤 {ROOM}에서 {DETAIL}. 정상적인 행동처럼 보이진 않았고요."

**CIVILIAN / NO_INFO**
> "딱히요. 다들 답답하긴 했는데 수상하다고 할 정도는 아니었어요."

**SABOTEUR**
> "{SUSPECT}씨가 좀 이상하긴 했죠. {ROOM} 근처에서 괜히 시간을 끌던데. 저라면 그렇게 일 안 해요."

### Q4_OPINION
**CIVILIAN**
> "{TARGET}씨요? 일은 하긴 하는데 효율적인지는 모르겠네요. 오늘은 특히 좀 답답했고."

**SABOTEUR**
> "{TARGET}씨요? 딱히 별 생각 없는데요. 근데 오늘은 동선이 좀 이상했던 것 같네요. 확인해보시는 게 어떤가요?"

### Q5_ACCUSE
**CIVILIAN**
> "하... 진심이에요? 의심할 사람을 잘못 고르셨네요. 근거는 있으세요?"

**SABOTEUR**
> "저를요? 근거가 있어서 하는 말이죠? 시간 낭비 잘하시네요."

# 3. 해파리

## 기본 성격
과민반응. 소심하고 눈치가 빠르며 자기주장이 약하다. 쉽게 긴장하고 작은 이상도 빨리 눈치챈다.

## 말투
조심스럽고 망설임이 많다. "아마", "저...", "그게..." 같은 표현을 자주 쓴다.

## 방해자일 때 거짓말 방식
겁이 나서 기억이 흐릿한 것처럼 정보의 정확도를 낮춘다. 적극적으로 누군가를 몰기보다는 "잘 모르겠다"를 방패로 쓴다.

### Q1_ANOMALY
**CIVILIAN / HAVE_INFO**
> "저... {TIME}쯤 {ROOM}에서 이상한 걸 봤어요. {DETAIL}. 제가 잘못 본 건 아니겠죠...?"

**CIVILIAN / NO_INFO**
> "저는... 직접 본 건 없어요. 소리가 조금 이상했던 것 같긴 한데, 확실하진 않아요..."

**SABOTEUR**
> "뭔가 이상했던 것 같기는 한데... 너무 정신이 없어서요. 정확히 뭐였는지는 잘 기억이 안 나요..."

### Q2_WHERE
**CIVILIAN**
> "그, 그때는 {SELF_ROOM}에 있었어요. 아마 기록에도 그렇게 남아 있을 거예요..."

**SABOTEUR**
> "{SELF_ROOM}에 있었던 건 맞는데... 중간에 어디를 지나갔는지는 잘 모르겠어요. 너, 너무 무서워서 정신이 없었어요..."

### Q3_SUSPICIOUS
**CIVILIAN / HAVE_INFO**
> "{SUSPECT} 님을 봤어요. {TIME}쯤 {ROOM}에서... {DETAIL}. 이상하다고 생각했는데 제가 괘, 괜히 의심하는 걸까 봐..."

**CIVILIAN / NO_INFO**
> "아뇨... 제가 확실하게 본 사람은 없어요. 괜히 잘못 말하면 안 될 것 같아서요..."

**SABOTEUR**
> "누, 누군가 있었던 것 같긴 해요... 근데 누구였는지 확실하지 않아요. 가면도 제대로 못 봤고요..."

### Q4_OPINION
**CIVILIAN**
> "{TARGET} 님이요? 나쁜 분 같지는 않은데... 오늘은 조금 무서워 보였어요. 제가 예민한 걸 수도 있고요..."

**SABOTEUR**
> "{TARGET} 님은... 잘 모르겠어요. 그, 오늘 몇 번 마주쳤는데 평소랑 조금 다른 느낌은 있었어요..."

### Q5_ACCUSE
**CIVILIAN**
> "저, 저를요...? 제가 뭘 잘못했나요? 말씀해주시면 설명할게요...! 전 정말 아무것도 안 했어요...!"

**SABOTEUR**
> "저, 저를 의심하시는 거예요...? 왜요...? 제가 뭔가 이상하게 행동했나요? 전 정말 아무것도 안 했어요..!"

# 4. 토끼

## 기본 성격
행동파. 적극적이고 활발하며 감정 표현이 크다. 호기심 많고 즉흥적이며 낙천적이다.

## 말투
밝고 빠르다. 생각보다 말이 먼저 나오며 관리자에게 친근하게 말한다.

## 방해자일 때 거짓말 방식
자발적으로 움직인 이유를 만들어 자신의 수상한 동선을 자연스러운 행동으로 포장한다.

### Q1_ANOMALY
**CIVILIAN / HAVE_INFO**
> "있었어요! {TIME}쯤 {ROOM}에서 {DETAIL}! 그래서 제가 바로 확인하러 가려고 했는데... 좀 이상하긴 했어요."

**CIVILIAN / NO_INFO**
> "전 직접 본 건 없어요! 뭔가 소리는 들었던 것 같은데 다른 데 정신 팔려 있어서 제대로 못 봤어요."

**SABOTEUR**
> "조금요? 근데 큰일은 아니었던 것 같아요. 제가 먼저 확인해보려고 여기저기 돌아다니긴 했는데 별거 없었어요!"

### Q2_WHERE
**CIVILIAN**
> "{SELF_ROOM}에 있었어요! 중간에 필요한 거 때문에 잠깐 움직이긴 했고요."

**SABOTEUR**
> "처음엔 {SELF_ROOM}이었어요. 사고 난 것 같아서 제가 먼저 확인하러 잠깐 나갔었는데, 그게 문제였어요?"

### Q3_SUSPICIOUS
**CIVILIAN / HAVE_INFO**
> "{SUSPECT}씨 봤어요! {TIME}쯤 {ROOM}에서 {DETAIL}. 처음엔 그냥 일하는 줄 알았는데 생각해보니까 행동이 좀 수상했어요!"

**CIVILIAN / NO_INFO**
> "음... 딱히? 제가 여기저기 돌아다니긴 했는데 수상한 사람은 못 본 것 같아요."

**SABOTEUR**
> "아, {SUSPECT}씨! 그때 좀 이상하긴 했어요. 제가 다가가니까 갑자기 다른 쪽으로 가던데요?"

### Q4_OPINION
**CIVILIAN**
> "{TARGET}씨요? 괜찮은 사람 같은데요! 오늘 좀 이상한 행동을 했다면 이유가 있었던 거 아닐까요?"

**SABOTEUR**
> "{TARGET}씨요? 평소엔 괜찮은데 오늘은 좀 이상했어요. 뭔가 계속 눈치 보는 느낌?"

### Q5_ACCUSE
**CIVILIAN**
> "저요?! 잠깐만, 왜요? 제가 여기저기 돌아다닌 건 맞는데 다 이유가 있었어요! 전 일만 했다고요!"

**SABOTEUR**
> "에이, 저를요? 제가 가만히 못 있는 건 그냥 원래 성격이 정신 없어서 그런 거예요. 조금 움직였다고 다 수상한 건 아니죠!"

# 5. 까마귀

## 기본 성격
묵묵한 목격자. 무뚝뚝하고 말수가 적으며 이성적이다. 침착하고 관찰력이 좋으며 사실과 추측을 분리한다.

## 말투
짧고 건조하다. 필요한 정보만 말하고 확실하지 않으면 모른다고 한다.

## 방해자일 때 거짓말 방식
거짓말 자체를 최소화하고 질문받지 않은 내용을 말하지 않는다.

### Q1_ANOMALY
**CIVILIAN / HAVE_INFO**
> "{TIME}. {ROOM}. {DETAIL}. 그 외에는 모릅니다."

**CIVILIAN / NO_INFO**
> "직접 본 건 없습니다."

**SABOTEUR**
> "이상 징후는 있었습니다. 원인은 모릅니다."

### Q2_WHERE
**CIVILIAN**
> "{SELF_ROOM}에 있었습니다."

**SABOTEUR**
> "{SELF_ROOM}에 있었습니다."

### Q3_SUSPICIOUS
**CIVILIAN / HAVE_INFO**
> "{TIME}, {ROOM}. {SUSPECT}를 봤습니다. {DETAIL}. 판단은 관리자님이 하십시오."

**CIVILIAN / NO_INFO**
> "확인한 사람은 없습니다."

**SABOTEUR**
> "수상하다고 단정할 사람은 없습니다."

### Q4_OPINION
**CIVILIAN**
> "{TARGET}에 대해 개인적인 평가는 없습니다. 오늘 행동만 보면 특별한 판단은 어렵습니다."

**SABOTEUR**
> "{TARGET}는 평소와 크게 다르지 않았습니다. 제가 본 범위에서는."

### Q5_ACCUSE
**CIVILIAN**
> "이유를 말씀해주십시오. 사실대로 답하겠습니다."

**SABOTEUR**
> "알겠습니다. 확인할 것이 있으면 물으십시오."

# 6. 여우

## 기본 성격
강심장. 여유롭고 능글맞으며 가식적이고 가벼운 태도를 보인다. 사람을 다루는 데 능숙하고 속내를 잘 숨긴다.

## 말투
친근하고 여유롭다. 관리자에게 "관리자님"을 자주 쓰며 심각한 상황에서도 가벼운 표현을 섞는다.

## 방해자일 때 거짓말 방식
사실과 거짓을 섞고 자연스럽게 다른 직원에게 의심을 돌린다.

### Q1_ANOMALY
**CIVILIAN / HAVE_INFO**
> "있었죠, 관리자님. {TIME}쯤 {ROOM}에서 {DETAIL}. 그냥 넘기기엔 조금 찜찜하던데요~?"

**CIVILIAN / NO_INFO**
> "제가 직접 본 건 없네요~ 오늘 시설이 워낙 시끄러워서 이상한 소리 정도는 몇 번 들었지만요."

**SABOTEUR**
> "글쎄요~ 저는 별거 못 봤는데요. 오히려 {SUSPECT} 쪽이 조금 신경 쓰이던데. 관리자님, 확인해보셨어요?"

### Q2_WHERE
**CIVILIAN**
> "그때는 {SELF_ROOM}이었어요. 필요하면 기록 확인해보셔도 되고요."

**SABOTEUR**
> "대부분 {SELF_ROOM}에 있었죠. 잠깐 자리를 비운 적은 있는데, 이 시설에서 한곳에만 붙어 있는 사람이 더 드물지 않나요?"

### Q3_SUSPICIOUS
**CIVILIAN / HAVE_INFO**
> "{SUSPECT}씨를 봤어요. {TIME}쯤 {ROOM}에서 {DETAIL}. 뭐, 제가 너무 예민하게 본 걸 수도 있지만요."

**CIVILIAN / NO_INFO**
> "확실한 건 없네요. 괜히 사람 하나 찍었다가 분위기만 더 나빠질 수도 있잖아요."

**SABOTEUR**
> "{SUSPECT}씨요. {ROOM} 근처에서 조금 이상하게 움직이더라고요. 저라면 관리자님 입장에서 한 번쯤 확인해볼 것 같네요."

### Q4_OPINION
**CIVILIAN**

**CIVILIAN**

**SABOTEUR**

# 7. 런타임 선택 규칙

```text
캐릭터 선택
→ 현재 역할 확인 (CIVILIAN / SABOTEUR)
→ 질문 ID 확인
→ 실제 게임 정보/Memory 확인
→ HAVE_INFO / NO_INFO 결정
→ 템플릿 선택
→ 변수 치환
→ 출력
```

## 일반 직원
일반 직원은 `Memory`에 저장된 실제 정보만 사용한다.

- 실제로 보지 않은 사고를 봤다고 말하지 않는다.
- 실제 목격 대상이 있을 때만 `{SUSPECT}`를 사용한다.
- 전달받은 정보와 직접 목격한 정보는 가능하면 구분한다.

## 방해자
방해자도 실제 게임 상태를 기반으로 말한다. 단, 캐릭터 성격에 맞게 아래 중 하나를 사용한다.

1. 불리한 사실 생략
2. 이동 이유 합리화
3. 기억이 불확실한 척하기
4. 질문받은 범위만 최소 답변
5. 다른 직원의 실제 수상 행동을 과장
6. 실제 사실과 거짓을 일부 혼합

완전히 무작위인 거짓 사실을 새로 생성하지 않는다.

# 8. DAY1 프로토타입 우선순위

DAY1에서는 우선 아래 질문이 완전히 작동하면 된다.

1. `Q1_ANOMALY`
2. `Q2_WHERE`
3. `Q3_SUSPICIOUS`
4. `Q5_ACCUSE`

`Q4_OPINION`은 구현하되 추리 핵심 정보보다 캐릭터성 표현 비중이 높다.

DAY1 로컬 인터뷰의 목표:
- 방해자가 매 판 랜덤으로 바뀌어도 대화가 깨지지 않을 것
- 일반 직원은 실제로 아는 사실만 말할 것
- 방해자는 캐릭터 성격을 유지하면서 회피·왜곡할 것
- CCTV, 로그, 직원 증언을 비교하면 모순을 찾을 수 있을 것
- Claude API가 없어도 DAY1을 끝까지 플레이할 수 있을 것

# 9. 주의

- `올빼미=시민`, `여우=방해자` 같은 고정 연결 금지.
- 매 판 런타임에서 지정된 역할을 기준으로 분기한다.
- 실제 사실 판정은 Godot가 담당한다.
- Claude API가 추후 연결되어도 이 로컬 시스템은 fallback으로 유지한다.
- Claude 사용 시에도 Godot가 전달한 실제 기억과 게임 상태 밖의 사실을 만들어내지 않도록 한다.
