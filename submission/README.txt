야간근무지침 (NIGHT SHIFT PROTOCOL)
제작: 백시하

지하 봉쇄 시설의 야간 관리자가 되어, 여섯 직원을 배치해 무너진 봉쇄 코어를 복구하고
직원들 사이에 숨은 "결번(방해자)"을 찾아내는 1인칭 관리 / 추리 호러 게임입니다.


[ 실행 ]
- NSP.exe 를 실행합니다.
  같은 폴더의 NSP.pck 와 data_NSP_windows_x86_64 폴더가 반드시 함께 있어야 합니다.
- 권장 환경: Windows 10 / 11 (64비트), DirectX 12 또는 Vulkan 을 지원하는 그래픽 카드
- 처음 실행하면 그래픽 장치에 맞춰 화질이 자동으로 정해집니다.
  (환경 설정 > 그래픽 품질 에서 언제든 바꿀 수 있습니다)
- 화면 기준 해상도는 1920 x 1080 입니다.


[ 플레이 시간 ]
- 단기 근무 한 번(프롤로그, 교육, 근무 3일, 엔딩 포함): 약 30분 안팎
- 이야기는 화면 오른쪽 위 SKIP 으로 건너뛸 수 있습니다.


[ 조작 ]
- 마우스: 모니터를 눌러 가까이 보기, 미니맵에서 직원을 끌어 다른 방에 배치
- 1 / 2: 모니터 1 / 모니터 2 확대
- 3 또는 Tab: 관리자 패드 꺼내기 (지침, 단서, 직원 정보)
- 4: 전력 기기 확대 (조명, CCTV, 차폐문에 전력 배분)
- T / L / D: 오늘의 업무 / 시설 로그 / 대화 기록
- ESC: 일시정지, 창 닫기
- 조작 키는 환경 설정에서 바꿀 수 있습니다.
- 시작 화면 오른쪽 모니터의 [조작 안내] 에서 같은 내용을 볼 수 있습니다.


[ 목표 ]
1. 근무가 시작되기 전에 직원을 작업실에 배치합니다. 비워 둔 방은 고장 납니다.
2. 근무 중에는 경고와 사고에 사람을 보내 고치고, 이상 개체는 CCTV 로 위치를 지켜봅니다.
3. 휴게시간에는 조사 자료(시설 로그, CCTV, 증언)를 골라 직원을 심문합니다.
   자료 두 장을 함께 내밀면 어긋나는 진술을 추궁할 수 있습니다.
4. 마지막 보고서에서 결번을 지목합니다.


[ 엔딩 ]
엔딩은 네 가지이고, 두 가지로 갈립니다: 코어를 목표까지 복구했는가 / 결번을 바르게 지목했는가.
- TRUE  : 코어 복구 목표 달성 + 결번 지목 성공
- LOOSE : 코어 복구 목표 달성 + 지목 실패
- LATE  : 코어 복구 실패 + 결번 지목 성공
- BAD   : 코어 복구 실패 + 지목 실패
본 엔딩은 시작 화면 오른쪽 모니터 아래의 ENDING 칸에 기록됩니다.
엔딩을 하나라도 보면 시작 화면의 [정규 근무](5일, 교육 없이 DAY1 부터)가 열립니다.


[ 주의 ]
- 이 게임에는 붉게 점멸하는 조명, 번쩍이는 화면, 흔들리는 화면 연출이 있습니다.
  빛에 민감하다면 환경 설정 > 화면 > [깜빡임 줄이기] 를 켜 주십시오.
- 공포, 유혈, 사망 묘사가 포함되어 있습니다.
- 근무 도중에는 저장되지 않습니다. 시작 화면으로 나가면 처음부터 다시 시작합니다.
